# 不做飞书 ID 登录

HR NEXT 是跨公司社群，成员分散在各自公司的飞书租户里。飞书**自建应用是单租户的** —— OAuth 与网页免登只对应用所属企业的成员生效，外部成员登不进来。要跨租户只能走 ISV 商店应用：申请 ISV 服务商（企业资质审核）、后端改造成 `app_ticket → app_access_token → 按 tenant_key 取 tenant_access_token`、用户主键改为 `tenant_key + open_id`、再过平台审核与每个租户管理员的二次授权。对一个社群自发项目，这个成本和周期都不成立。

因此本项目**不以飞书身份作为登录态**。作为参照：Serena 公司的 HRAS AI 岛能用飞书 ID，是因为那是同一家公司的内部系统（单租户 + 内网），前提条件与本项目相反 —— 它的方案不可直接照搬。

飞书仍然承担运营通道的角色（外部群推送、群机器人、多维表格），只是不承担鉴权。
